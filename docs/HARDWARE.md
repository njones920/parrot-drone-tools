# Hardware

No SDR, drone, radio, or GPU is required to install Parrot Drone Tools.

Hardware support comes from the radio backends and capture helpers already in
Parrot's archive. Users should select equipment for the frequencies and protocols
they intend to examine. In particular, coverage at 868/915 MHz does not imply
coverage at 2.4 or 5.8 GHz, and an antenna must cover the band being monitored.

This project does not flash radio firmware or automatically change USB, display,
kernel, Secure Boot, or graphics-driver configuration.
