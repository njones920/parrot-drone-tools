# Package scope

Parrot Drone Tools is a curated view of software already supplied by Parrot OS.
It adds a metapackage and a menu domain; it does not replace Parrot's repositories.

The menu provides six working categories:

- SDR and RF analysis
- Remote ID and DroneID foundations
- MAVLink and ground-control foundations
- GNSS and GPS
- Counter-UAS and airspace awareness
- Firmware and hardware analysis

General password recovery, forensics, reverse engineering, and web tooling remain
in Parrot's existing tool domains. Hardware drivers, vendor firmware, NVIDIA
configuration, custom kernels, source builds, and the maintainer's private
`/opt/drone` environment are intentionally outside this repository.
